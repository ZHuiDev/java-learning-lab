# Java 项目学习知识地图

这套路线以 **JDK 21、不启用预览特性** 为基线，共 8 个阶段、40 课。目标是建立覆盖广的 Java 核心与工程知识体系，能独立开发、验证和解释一个中小型项目。Java 生态没有有限的“全部知识清单”：框架、行业协议和新版本会持续变化，后端与分布式部分明确列为后续拓展。

你已经懂基本语法，因此建议 **01—05 先做诊断复习，主线从 06 开始**。先预测输出、解释边界、完成练习；若基本类型、数组、字符串与异常有明显缺口，再回到对应课复习。不需要机械重学所有已掌握语法。

## 学习证据与项目边界

本项目贯穿同一条业务主线：**Campus Library 校园图书借阅系统**。`Book` 表示图书及馆藏库存，`Loan` 表示某笔借阅及归还状态，`LibraryService` 组织借还用例，`LibraryRepository` 保存完整状态快照。图书可以被不同读者先后借阅，同一书目也有多册库存；“已归还”属于某条 Loan，不能作为 Book 的完成状态。

当前工程使用 JDK 21，不引入第三方库。已有图书搜索、分类筛选、借阅、归还、基础统计、文件持久化与本地 HTTP 页面，默认地址为 `http://127.0.0.1:8787`。借期固定为 **借阅日加 30 天**，应还当天不算逾期。服务在新快照保存成功后才发布内存状态；真实数据库、登录鉴权、Spring 与消息系统尚未实现。

9 个可运行实验分别观察基础费用、借阅策略、图书目录、借阅统计、文件清单、并发库存、借阅结果、注解扫描、JVM 快照。实验是主题演示，例如 OopLab 的学生 14 天/教师 30 天策略尚未接入主系统；主系统仍固定 30 天。课程里的单文件 Book/Loan 小类是逐步演进的独立简化模型，不应直接覆盖 `lab.domain` 下的完整 record。标签、归还时刻、历史实际借阅时长等新增字段，均需自己实现并处理文件格式兼容。

页面“运行实验”调用的是该主题已有的演示，**不会自动编译本页每一段示例，不会执行你的练习，也不会证明你已掌握本课**。课程中的完整小类可以另存到独立练习目录编译；标明“片段”“多文件”“需外部依赖”的示例需要补齐上下文。项目自检通过只证明它实际覆盖的场景在当前环境中通过。

状态约定：

- **已实现演示**：当前源码确实包含相应机制，可以运行观察；不是完整产品能力。
- **示例与练习**：课程给出讲解、独立代码或参考解；需要你自己修改、编译、测试。
- **外部拓展**：需要额外工具、驱动、数据库、框架或服务。项目不自动安装、部署或提供这些能力。

## 40 课与当前实现的对应关系

| 课 | 主题 | 当前工程中的证据与边界 |
|---|---|---|
| 01 | 编译、运行、JDK/JVM、main | 已有 Java 工程和启动脚本；Hello 命令行参数示例由你独立练习。 |
| 02 | 基本类型、包装类、溢出、BigDecimal | `BasicsLab` 演示基本类型、整数除法和 BigDecimal；包装类拆箱、精确溢出检查为课内练习。 |
| 03 | 分支、循环、数组、边界 | `BasicsLab` 演示循环与分支；数组统计、二维数组与边界处理为练习。 |
| 04 | String、Unicode、文本块、regex | 工程使用 String/StringBuilder；代码点计数、Pattern 与输入清洗需独立练习。 |
| 05 | 方法、按值传递、异常、调试 | `BasicsLab` 有方法和非法参数异常；解析与断点定位需你动手。 |
| 06 | 类、封装、构造器、static | 本课可变 Book 练习书名与库存不变量；`OopLab.Book` 演示单本借出状态。主领域 Book 已演进为不可变 record。 |
| 07 | 接口、继承、多态、组合 | `OopLab.LoanPolicy` 展示接口策略与多态；课程通知接口为独立练习，差异借期未接入主服务。 |
| 08 | equals/hashCode、身份与值 | `CollectionsLab.Book` 按不可变 ISBN 实现相等与哈希；手写 BookId 为练习，主系统以稳定图书 id 标识书目。 |
| 09 | enum、record、不可变 | 主领域 `Book`/`Loan` 与 `ModernLab` 使用 record；库存可用性枚举、标签列表的防御性复制为独立练习。 |
| 10 | 分层、仓储、构造器注入 | 主服务已有 `LibraryService(LibraryRepository, Clock)`，文件实现读写整体 Snapshot；用内存与失败保存替身验证旧状态不被部分修改。 |
| 11 | List、集合视图、迭代删除 | `CollectionsLab` 展示 List；从借阅历史副本筛选未归还记录，不能删除主仓储的归还历史。 |
| 12 | Set、Map、哈希、顺序 | `CollectionsLab` 展示 LinkedHashSet、LinkedHashMap、merge 与按 ISBN 去重。 |
| 13 | 泛型、PECS、擦除 | 工程有类型化集合；通配符复制方法、泛型 Page 和堆污染边界为课内示例与练习。 |
| 14 | Comparator、排序、复杂度 | `CollectionsLab` 按书名排序；按 Loan 应还日期/编号排序与借阅次数降序由你扩展。 |
| 15 | Optional、空值、契约 | `StreamsLab` 演示 Optional 缺失结果；不同用例的错误策略为练习。 |
| 16 | Lambda、函数式接口、方法引用 | `StreamsLab` 使用 Lambda 和方法引用；Predicate 组合为练习。 |
| 17 | Stream、Collector、分组 | `StreamsLab` 展示借阅统计；课程增加次数、已借日数与当前逾期统计的独立快照。历史真实时长需新增归还日期。 |
| 18 | Path、Files、UTF-8、资源关闭 | `IoLab` 演示写读与关闭；`FileLibraryRepository` 已有完整快照保存。课内 id/书名导出是独立格式，不能覆盖完整状态文件。 |
| 19 | java.time、时区、Clock、金额比较 | 主服务注入 Clock，用 LocalDate 计算固定 30 天借期；时间边界、时区与 BigDecimal 比较需你补充练习。 |
| 20 | 字节流、二进制格式、序列化风险 | DataInput/DataOutput 为独立版本化图书导出练习；当前仓储已有自己的格式，二进制练习不能视作已替换主格式。 |
| 21 | 线程生命周期、中断、JMM | 并发演示中有任务完成协调；直接 Thread/start/join、中断和 happens-before 为补充示例与推理练习。 |
| 22 | synchronized、volatile、锁 | `ConcurrencyLab.Inventory` 用同步方法保护检查与扣减；volatile 不保证复合原子、死锁与 ReentrantLock 为讲解/练习。 |
| 23 | Executor、Future、异步组合 | `ConcurrencyLab` 提交任务并通过 Future 汇总；超时、取消与 CompletableFuture 需独立补做。 |
| 24 | 原子类、并发集合、协调器 | `ConcurrencyLab` 用 AtomicInteger 计数；ConcurrentHashMap、CountDownLatch、BlockingQueue 为独立示例/练习。 |
| 25 | 虚拟线程、资源预算 | `ConcurrencyLab` 实际使用虚拟线程执行器；Semaphore 上限与阻塞负载对比为练习。 |
| 26 | JVM、类加载、GC、可达性 | `JvmLab` 读取类加载器、堆估算和 GC 统计；缓存保留、GC 日志与运行时原理需阅读与分析。 |
| 27 | 反射、注解、强封装 | `ReflectionLab` 扫描自有公开方法、读取 RUNTIME 注解并受控调用。 |
| 28 | sealed、record pattern、switch | `ModernLab` 实际展示 JDK 21 正式特性，不需要预览开关。 |
| 29 | JPMS、ServiceLoader、jdeps、jlink | **外部拓展**：需要独立多模块源码/构建配置；当前项目不等于已模块化发行镜像。 |
| 30 | JFR、jcmd、JMH、性能证据 | `JvmLab` 只有进程快照；JFR 小示例和诊断采集由你执行，完整 JMH 需额外依赖。 |
| 31 | HTTP、Socket、JSON、TLS | **部分已有**：JDK HttpServer 在本地 8787 提供 `/api/books`、`/api/loans` 等接口；HttpClient 可直接练习。通用 JSON 绑定库、底层 Socket 服务与 TLS 为拓展。 |
| 32 | 关系模型、SQL、约束、索引 | **外部拓展**：books/loans 是一对多模型，包含库存、日期和外键约束；打印 SQL 不代表已经建表。 |
| 33 | JDBC、参数绑定、连接 | **外部拓展**：需驱动与 schema；完整 JdbcLibraryRepository 必须保存 Book/Loan/编号状态，单条图书查询不等于完整快照仓储。 |
| 34 | 事务、隔离、乐观锁 | **外部拓展**：同连接内条件扣库存、增加版本并插入 Loan；需要真实数据库验证提交、第二步失败回滚与双连接冲突。 |
| 35 | 认证、授权、安全输入 | **外部拓展**：有授权规则片段；完整登录、密码哈希、会话、TLS 与安全框架未内置。 |
| 36 | 测试、失败路径、重构 | 工程自检是起点；需为自己的新功能新增行为测试，JUnit 另需依赖。 |
| 37 | Maven、Git、CI | **部分已有**：pom 已提供 JDK 21 编译/打包和 test 阶段自检；首次需下载插件。JUnit 迁移、远程仓库与 CI 为独立练习。 |
| 38 | Spring Boot、REST、框架原理 | **外部拓展**：需独立框架工程、依赖与启动/错误/安全配置，当前项目不捆绑 Spring。 |
| 39 | 缓存、消息、幂等、分布式 | **外部拓展**：只有单 JVM 内存示例，Redis/Kafka、持久幂等与故障注入需外部系统。 |
| 40 | 图书借阅毕业功能与交付 | 基于现有借还系统新增日期区间查询、报告导出或续借等独立功能；提交实现、测试与复盘，不能把现成借还流程或勾选课程当作毕业证据。 |

## 推荐节奏

以下是学习预算，不是掌握时间保证。页面 minutes 是首次阅读与观察的参考分钟数，编程练习和复盘通常需要额外时间。

1. **诊断（半天到 1 天）**：快速做 01—05 的题与练习。每个薄弱点写一句“我之前误解了什么”。
2. **对象与数据结构（约 2 周）**：06—15，重点完成封装、相等契约、仓储替身和集合选择。每周至少交付一次功能修改。
3. **数据处理与文件（约 1 周）**：16—20，交付统计与 UTF-8 导出/回读，测试坏输入与失败保存。
4. **并发与运行时（约 2 周）**：21—30，按共享不变量推理，解释锁与可见性，再做一次实际诊断。29 可暂后置。
5. **核心毕业（约 1 周）**：先做 36、40，在无需数据库的环境完成一个独立功能闭环。
6. **后端拓展（约 2—4 周或更久）**：先用 31 课观察现有 HTTP，37 课验证已有 Maven 构建，再练习 SQL/JDBC/事务、Spring 与分布式。数据库、框架、JUnit 与远程 CI 需要额外环境，每引入一个组件都补环境说明和故障验证。

每次学习按“**预测 → 运行 → 修改 → 验证 → 解释**”进行。对选择题先独立回答再查看解释；答对一次只是一次证据。隔两三天重新完成类似任务，能够不看参考解复现，再标记为掌握。

## 毕业验收

核心毕业不要求安装所有框架，但必须有你自己的功能代码与证据：

- 可在 JDK 21 干净环境按 README 编译运行，无预览开关；提交新增代码与可执行检查。
- 独立新增一条图书借阅功能，例如应还日期区间查询、借阅报告导出或续借，贯穿入口、业务规则与必要的存储变化；清楚写出数据格式及兼容边界。已有图书搜索、分类、借阅与归还不算新增功能。
- 正常、空结果、非法输入、持久化失败、边界日期五类场景有可复核记录；并发功能额外证明共享不变量和资源关闭。
- 可以解释封装、equals/hashCode、集合/泛型选择、异常传播、Stream、时区、线程安全与 JVM 诊断的关键判断。
- 能复盘一次真实失败：输入、症状、定位证据、根因、修复、回归检查及剩余风险。
- 将数据库、Spring、鉴权、消息、部署分别标为“已实现并验证 / 只完成设计 / 尚未开始”，不以默认演示或勾选状态代替实现。

后端拓展毕业需要额外展示数据库约束与回滚、注入防护、对象级授权、可复现框架工程和外部组件故障处理。分布式部分必须在多实例或等效受控环境中验证，单机 Map 无法替代这些证据。
